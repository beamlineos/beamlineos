# Pinned system UIDs and GIDs (0.0.4.3 step 0, docs/decisions.md D86, D106). DATA outlives every
# update and keeps its owners, so a system account's number never changes once a snapshot has

# systemd-sysusers runs (tools/pin-sysusers.py), then checks /etc/passwd and /etc/group against
# this table: an account missing here, or a stale line, fails the build.

# lowest one in use (sysusers' own range counts down from 999); never reuse a number.
